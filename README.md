# Atchii Assistant

Atchii è una piattaforma web accessibile per autonomia, gioco e apprendimento.

Include:

- assistente virtuale Atchii con voce calma
- giochi educativi eseguibili nel browser
- platform con addizioni
- pagina disegno con canvas
- comunicazione facilitata
- routine visive
- impostazioni accessibili
- supporto desktop, tablet e telefono

## Pubblicazione

Questo progetto è pronto per GitHub Pages. Il file principale è `index.html`.
